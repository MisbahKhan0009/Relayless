## Download

| Device | File |
|---|---|
| **Android** 7.0 or newer (any phone or tablet) | `Relayless-…-android.apk` |
| **Windows** 10 / 11 (64-bit) | `Relayless-Setup-…-x64.exe` |

**Android:** tap the `.apk` below on your phone, then **Install**. If asked, allow your browser or file manager to install apps. On first launch, allow *All files access* and notifications. If Play Protect shows a warning for this new app, tap **More details → Install anyway**.

**Windows:** run the installer (no administrator rights needed). If SmartScreen warns, click **More info → Run anyway**.

New builds install over the previous one and keep your paired devices and transfer history.
